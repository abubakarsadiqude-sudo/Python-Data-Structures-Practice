# Python Data Structures Practice 🐍

## 📌 Project Overview

This repository contains **10 practical Python programming tasks** focused on two important Python data structures: Lists and Tuples.

These exercises are designed to improve programming fundamentals, logical thinking, and problem-solving skills through practical implementation.

The repository is divided into two sections:

- Python List Practice – 5 Tasks
- Python Tuple Practice – 5 Tasks

## 🎯 Learning Objectives

After completing these exercises, you will be able to:

- Understand Python Lists and Tuples.
- Create, access, and manipulate data structures.
- Understand mutable and immutable data types.
- Use indexing and slicing.
- Apply built-in methods and functions.
- Work with loops and conditional statements.
- Perform mathematical operations.
- Compare and combine multiple tuples.
- Understand nested tuples.
- Develop a student result management system.

# 💡 Key Learning

Lists and Tuples are important built-in Python data structures.

- **List:** Mutable, meaning elements can be added, removed, and modified.
- **Tuple:** Immutable, meaning elements cannot be directly modified after creation.

This practice project focuses on building a strong foundation in Python data structures before moving towards advanced concepts such as Dictionaries, Sets, OOP, NumPy, and Pandas.
